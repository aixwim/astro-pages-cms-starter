# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately by email to starkowim@gmail.com.
Do not publish sensitive details in a GitHub issue.

Include the affected URL, a concise reproduction, expected impact, and any
supporting evidence that does not contain credentials or personal data. The
maintainer will acknowledge actionable reports as soon as practical and will
coordinate remediation before public disclosure.

## Scope

This policy covers the source code and GitHub Pages deployment of Aixwim
Insights. Third-party services linked from the site follow their own security
policies.

Never send passwords, access tokens, private keys, or identity documents.
