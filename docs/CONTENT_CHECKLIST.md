# Checklist konten

- [ ] Intent dan manfaat pembaca berbeda dari artikel lain
- [ ] Judul deskriptif, unik, dan tidak sensasional
- [ ] Deskripsi akurat dan natural
- [ ] Penulis, kategori, serta tanggal benar
- [ ] Heading membentuk alur yang jelas
- [ ] Contoh konkret dan batasan disertakan
- [ ] Fakta penting memiliki sumber yang layak
- [ ] Tidak ada keyword stuffing atau klaim fiktif
- [ ] Internal link relevan dan tidak rusak
- [ ] Artikel dibaca ulang untuk ritme, ejaan, dan pengulangan
